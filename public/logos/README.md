# Client logos

Drop client logo image files here (PNG or SVG with transparent background), then
reference them in `components/LogoBar.tsx`:

```ts
{ name: "Under Armour", logo: "under-armour.png" }
```

Guidelines:
- Use **white / light** versions of each mark — the marquee sits on a near-black
  bar, so dark or black logos won't be visible. (Natural full colour is fine for
  logos that are already light or vivid.)
- Aim for ~36px tall artwork with a transparent background.
- Use official brand assets you're licensed to display (most brands provide a
  press / brand-kit download). Avoid scraped or unlicensed files.
